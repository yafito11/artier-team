Everything you need

A complete platform for building and running AI agent teams, fully self-hosted.

Multi-Agent System

Create standalone agents or teams with Lead + Sub Agent hierarchy. Each agent has its own model, instructions, and skills.

Multi-Provider

Connect to OpenAI, Anthropic, or any compatible provider. Auto-detect models, BYOK, no vendor lock-in.

Agent Builder via Prompt

Describe what you need in plain language. AI generates complete agent configs with instructions and model suggestions.

CLI Execution Sandbox

Run terminal commands in isolated sandboxes. Agents can execute code, run tests, deploy — all safely sandboxed.

Automation & Cron

Schedule agents to run automatically. Daily reports, weekly digests, periodic checks — set it and forget it.

Self-Hosted

Deploy on your own infrastructure. Docker Compose on any VPS. Your data, your keys, your control.

How it Works

1

Connect Your Providers

Add your API keys from OpenAI, Anthropic, or any compatible provider. Models are auto-detected and ready to use.

2

Create Your Agents

Build agents manually or let AI generate them from a prompt. Define skills, choose models, write instructions.

3

Form a Team

Group agents into teams with a Lead Agent coordinating Sub Agents. Each team has a slash command for easy access.

4

Start Building

Chat with your agents, run skills, execute commands. Your AI team handles the rest — autonomously.
